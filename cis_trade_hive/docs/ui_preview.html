Issues visible in current design
Font: Renders as San Francisco on Mac, Segoe UI on Windows, Roboto on Linux — different weight, metrics, and spacing on each machine
badge-info (USD badges above): rgba(6,182,212,0.1) background — the alpha blends differently against white vs hover rows vs dark backgrounds. Contrast ~2.8:1 (WCAG fail)
Muted / timestamp / placeholder text: gray-400 (#94a3b8) — contrast 3.1:1 on white, fails WCAG AA for normal text
Price column (no tabular-nums): "178.3200" vs "36.5400" — proportional digits cause the decimal points to not align across rows
