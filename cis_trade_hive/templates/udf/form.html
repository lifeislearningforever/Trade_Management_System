    Object Type
    • The module this field belongs to (e.g., PORTFOLIO)
    • Cannot be changed after creation
    Field Name
    • The field definition (e.g., Portfolio Manager, Account Group)
    • Admin creates field definitions first

    1. Admin creates field definitions (Object Type + Field Name)
    2. Users add values for each field (the dropdown options)
